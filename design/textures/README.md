# Текстуры комнаты

Картинки, которые 3D-офис кладёт на пол и стены (`src/web/office3d/Office3D.tsx`).
Все они бесшовные и повторяются: одна картинка покрывает два тайла по каждой
оси (`FLOOR_TEXTURE_TILES`, `WALL_TEXTURE_TILES`). Формат — `.jpg` или `.png`.

Файла может не быть: тогда поверхность рисуется цветом из палитры
(`palette.ts`), как раньше.

## `floor/`

Файл называется как материал пола комнаты в раскладке (`rooms[].floor`):
`parquet.jpg` ложится на все комнаты с полом `parquet`. Имя материала —
любое, лишь бы совпадало с файлом; трём нарисованным (`parquet`, `carpet`,
`tile`) есть и цвет в палитре, и спрайты в плоском виде.

## `wall/`

Имя — грань стены:

- `inner` — сторона, смотрящая в комнату;
- `outer` — наружная сторона, за которой комнаты нет;
- `top` — торец сверху.

Какая грань наружная, считается из раскладки (`geometry.ts`, `sidesOf`):
за клеткой стены поперёк неё либо есть комната, либо нет.

## Кеш Vite

Список файлов в папке Vite читает, когда собирает `Office3D.tsx`, и держит
в кеше. Новый файл в пустой прежде папке он не заметит, пока модуль не
пересоберётся: тронуть `Office3D.tsx` или перезапустить `npm run dev`.
Замена файла с тем же именем работает по обычной перезагрузке страницы.
