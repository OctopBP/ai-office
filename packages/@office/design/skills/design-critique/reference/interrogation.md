# Допрос своей работы: пять уровней

Вопросы — наши, адаптированы под продуктовый интерфейс с жёсткой дизайн-системой.
Идея пяти уровней взята из статьи Anthropic Academy «Elevate Claude's design using
skills», формулировки свои. Ответы держи в голове или в черновике; в отчёт идёт
только итог (см. `SKILL.md`).

## 1. Зачем (первые принципы)

- Какую одну задачу человек решает на этом экране? Если задач три — какая главная?
- Что человек должен увидеть за первую секунду? Это сейчас самое заметное?
- Откуда он пришёл и куда уйдёт дальше? Выход и следующий шаг видны?
- Можно ли решить задачу без этого экрана (в соседнем, тостом, строкой)?

## 2. Разбор элементов

Для каждого блока, текста, иконки, разделителя:

- Чему он служит? Ответ «для красоты» или «так принято» — кандидат на удаление.
- **Шрифт.** Сколько уровней иерархии реально нужно? Главное отличается кеглем
  или начертанием так, что это видно с расстояния вытянутой руки?
- **Цвет.** Где акцент? Если акцентов больше одного на экран — какой лишний?
  Цвет несёт смысл (статус, выбор) или красит?
- **Сетка и отступы.** Группы читаются по отступам без рамок? Внутри группы
  отступ меньше, чем между группами? Выравнивание по одной оси или «всё по центру»?
- **Рамки, тени, фоны.** Каждая граница что-то отделяет? Можно ли отделить отступом?

## 3. Сверка с образцом

- Какой существующий экран офиса ближе всего? (`docs/design/*`, стенд `?kit=1`,
  `src/web/styles/kit.css`.) Новый экран говорит на его языке или спорит?
- Для артефактов и презентаций: на какой известный образец опираемся и что
  именно берём (иерархию, ритм, сдержанность цвета) — назови одним словом.
  Опора на образец проверяема; «современно» — нет.

## 4. Не шаблон ли

- Если стереть название продукта — экран можно спутать с тысячей других?
- Есть ли в нём решение, которое следует из этой задачи, а не из привычки?
- Сверка со штампами: `ai-tells.md`.

## 5. Тест на удаление

- Убери по очереди каждый элемент мысленно. Что сломалось? Ничего — убери.
- Убери половину текста. Смысл остался? Значит, половина была лишней.
- Убрал — посмотри снова: не появилось ли нового главного, которое теперь тонет?
- Верни только то, без чего задача не решается. Список убранного — в отчёт.
