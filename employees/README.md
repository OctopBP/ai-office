# Наборы ролей, заведённых руками

Пакеты агентов переехали в [`packages/`](../packages/README.md): там лежат
наши `@office/*` с манифестом, брифами и скилами, и оттуда заводятся роли
нового офиса.

Эта папка осталась для одного случая: роль заведена из формы (или отвязана от
пакета) и ей нужны свои скилы. Имя папки — id роли:

```
employees/<роль>/
  .claude-plugin/plugin.json     имя, версия, описание
  skills/<навык>/SKILL.md        свои навыки
  agent.json                     те же поля, что у пакета: skills, builtin, use, servers
                                 (старый pack.json читается по-прежнему)
```

Роли здесь не описываются — она уже есть в офисе. Правила про скилы, чужие
наборы и просьбы о серверах те же, что у пакетов, и описаны там.
