# Каталог моделей Codex

`GET /api/providers/codex/models` — метаданные установленного Codex без сохранения настроек и запуска хода модели. Ответы не кешируются (`Cache-Control: no-store`).

Общий тип: `КаталогCodex` в `src/shared/codex.ts`.

Успех, HTTP 200:
```json
{
  "ok": true,
  "models": [{
    "id": "имя-модели",
    "label": "Название модели",
    "supportedReasoningEfforts": [{
      "reasoningEffort": "уровень-из-каталога",
      "description": "Описание Codex"
    }],
    "defaultReasoningEffort": "уровень-из-каталога",
    "isDefault": true
  }]
}
```

`id` берётся из upstream-поля `model` (как в текущем адаптере Codex), `label` — из `displayName`. Усилия, их описания, умолчание и признак модели по умолчанию приходят от Codex. Значения усилий не ограничены зашитым перечнем. Скрытые модели исключены. `models: []` означает успешный пустой каталог.

Ошибка получения, запуска app-server, таймаут, несовместимые метаданные или ошибка любой страницы: HTTP 502:
```json
{
  "ok": false,
  "code": "catalog-unavailable",
  "message": "Не удалось получить каталог установленного Codex. Проверьте установку, вход и доступ к сервису."
}
```
В ошибке нет `models`, частичных данных и резервных вариантов. Диагностика процесса не раскрывается. Другие HTTP-методы возвращают 405 с `Allow: GET` и `{ "error": "Используйте GET" }`.

Каталог означает доступность вариантов по данным установленного app-server; успешное выполнение платного хода им не проверяется.

## Источник и проверка

03.11.2026 проверена схема установленного Codex 0.165.0 (папка платформы `0.165.0-darwin-arm64`): `app-server generate-ts`, типы `v2/Model`, `ModelListParams`, `ModelListResponse`, `ReasoningEffortOption`. Используется существующий транспорт `CodexRpc` и поиск бинарника/окружение из `providers/codex.ts`: `initialize`, уведомление `initialized`, затем `model/list` с `limit: 100, includeHidden: false, cursor`. Следующая страница определяется `nextCursor`, null завершает выдачу. Повтор курсора и чрезмерное число страниц считаются ошибкой. Соединение закрывается при любом результате.

Из T-800/T-799.stopped-1 повторно использованы названия полей метаданных; настройки, наследование и проверка сохранённого выбора из старого патча не переносились.

`npm run test:codex-каталог` проверяет пагинацию, точную передачу усилий, фильтрацию скрытых моделей, пустой каталог, ошибки старта/инициализации/страниц, повреждённую схему, повтор курсора, закрытие RPC, HTTP-коды и тело ответа без открытия порта. `npm run typecheck` проходит.

Живой запрос к установленному Codex также завершился успешно: получено 9 моделей с усилиями из ответа. Этот замер не фиксирует список в коде и не гарантирует будущую доступность.
