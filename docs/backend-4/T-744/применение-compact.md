## Условия возобновления

**Разрешение на retry_review: нет.** Не выполнены установка исправленного ресурса, подтверждение его загрузки новым сервером и проверка отсутствия старой активной сессии ревьюера.

Снимок `office/offices/o-2.json` содержит у `reviewer#1` сохранённый `sessionId` `codex:01a18e0e-7398-7db3-8849-7c9be0844c8b` (тот же `reviewerSessionId` T-742). Сохранённый идентификатор не доказывает активность или завершение процесса. Проверить живую активность через API в этой сессии нельзя; отсутствие старой активной сессии **не подтверждено**. Если она активна, PM должен сначала штатно остановить её.

После внешнего шага нужно сверить ресурс (старого завершения внутри `contextCompaction` нет), новый запуск сервера после обновления и отсутствие старой активной сессии. Только после этих подтверждений PM может продолжить существующие ревью штатным `retry_review` с сохранением остальных ограничений. Сам исполнитель retry_review не запускал; тесты, исходный код, workflow и бюджеты не менял.
