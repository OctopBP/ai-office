## 1. Информационная архитектура

### 1.1. Модель в одной фразе

Офис — одно пространство: **Холст** показывает один из режимов (Чат или Доска; Сцена — по настройке) и всегда стоит над одним **Композером**; офисы — вкладки сверху. Всё остальное — **Лист**: одна форма, выезжающая справа; открывается клавишей раздела, из меню «Разделы ▾» или из Палитры.

### 1.2. Дерево

```
ПРИЛОЖЕНИЕ
│
├─ СТРОКА ОФИСОВ (постоянная, 48 px, вся ширина)
│   ├─ слева: ВКЛАДКИ ОФИСОВ  [Приложение ● 2] [Лендинг ⏸ 1] [Исслед. ○]  [+]
│   │         • имя, иконка, точка состояния, число «ждёт меня», жирное имя = непрочитанное
│   │         • «⋯»/правый клик по вкладке: Пауза, Переименовать, Иконка, Не беспокоить,
│   │           Архивировать… (закрытия вкладки нет)
│   │         • «Все офисы ▾» — когда вкладки не помещаются (5+): все офисы, статус,
│   │           «что делает», поиск
│   │         • «+» → Лист «Новый офис»
│   └─ справа: [Чат│Доска│(Офис)] · [Ждёт меня 4] · [⏸] · шкала лимита · [⌘K] · [Разделы ▾]
│
├─ ПОЛОСА СИГНАЛОВ (по событию, 36 px, внутри холста) — ошибка соединения,
│                    нет провайдера, идёт обновление; не больше одной
│
├─ ХОЛСТ (весь остаток) — один РЕЖИМ офиса, запоминается за вкладкой
│   ├─ Режим ЧАТ (основной)    ← шапка холста: «Чаты ▾» (список чатов с PM, + поиск,
│   │                            переименование, архив), карточки задач чипами в тексте
│   ├─ Режим ДОСКА   (B)       ← шапка: [Задачи│Направления│План], фильтры;
│   │                            «Сейчас»: кто что делает — строка над колонками
│   └─ Режим ОФИС (Сцена)      ← только если включён в Настройках › Приложение;
│                                иначе сцена — Лист «Офис» (O)
│
├─ КОМПОЗЕР (постоянный, 72 px) — всегда пишет менеджеру активного офиса;
│                                  в «Чат» — сообщение, в «Доска» — постановка задачи
│
└─ ЛИСТ (одна форма, справа поверх холста; один за раз; Esc/✕ закрывает, «←» назад)
    │
    ├─ ГЛОБАЛЬНЫЕ (не принадлежат офису, остаются при смене вкладки)
    │    ├─ Ждёт меня (по всем офисам)                       ⌘I   — ЯДРО
    │    ├─ Новый офис (мастер, быстрый путь — первый шаг)   «+», ⌘⇧N
    │    ├─ Офисы (управление: порядок, иконка, архив)       меню «Разделы» › Офисы
    │    ├─ Настройки приложения                             S → «Приложение»
    │    │     Внешний вид (в т. ч. «режим Офис») · Клавиши и справка · О приложении
    │    └─ Справка по клавишам                               ?
    │
    └─ ПРИНАДЛЕЖАТ ОФИСУ (запоминаются за вкладкой)
         ├─ Задача T-n   (карточка: статус, разговор, «Что случилось», результат,
         │                «Изменения» = дифф, «Ход работы» по задаче)     — РАБОЧЕЕ, из чипа/доски
         ├─ Сотрудник    (карточка сотрудника; из Сцены, Команды, упоминания)
         ├─ РАБОЧЕЕ (≤ 2 уровней внутри)
         │    ├─ Офис (Сцена, если не режим)                        O
         │    ├─ Документы   (категории слева, документ справа)      D
         │    ├─ Расходы     (Сегодня | По задачам | Отчёт | Лимиты и бюджет)   E
         │    ├─ Команда     (В офисе | Маркет; список + деталь)    T
         │    ├─ Журнал      (журнал, инициативы, предложения)       J
         │    ├─ Ход работы  (События = Лог | Очередь слияния)       L / Q
         │    ├─ Выпуски     (3 вкладки как сейчас)                  R
         │    ├─ Совещания   (идущие, архив, форма созыва)           M
         │    └─ Терминал                                            Ctrl+`
         └─ РЕДКОЕ (до 3 уровней)
              ├─ Процессы   (4 вкладки как сейчас)                   P
              └─ Настройки офиса (8 разделов как сейчас: Проект ·
                                  Правила · Окружение · Провайдеры · …)   S

МОДАЛКА (единственная): Запрос разрешения инструмента — только в активном офисе;
                        Esc «откладывает» (запись остаётся в «Ждёт меня»).
```

| **Композер** | 72 (растёт до 160), по ширине холста | Подпись «Менеджер · Приложение», поле, `+` вложение, `↑` | Один на офис. Под Листом не прячется. Черновик хранится за вкладкой |
| **Лист** | обычный 520 × 780 (x 920–1440) или широкий 920 × 780 (x 520–1440); y 48–828 | Шапка 48: `←` (если есть история), заголовок, `⤢/⤡` (обычный ↔ широкий), `✕`. Тело 732; у форм — липкая панель действий 64 | Один за раз; слой `--z-drawer`; композер остаётся доступным |

Расчёт: холст 780 = 900 − 48 − 72; тело холста 736 = 780 − 44; тело Листа 732 = 780 − 48.

### 2.2. Ширина Листа

Ширина — свойство раздела, а не выбор пользователя; кнопка `⤢` лишь меняет её на время сессии.

| Обычный (520) | Широкий (920) |
|---|---|
| Ждёт меня, Задача, Сотрудник, Расходы, Выпуски, Совещания, Журнал, Справка, Новый офис, Офисы | Команда, Документы, Настройки, Процессы, Ход работы, Терминал, Офис (Сцена) |

### 2.3. Что с холстом, пока Лист открыт

Лист визуально поверх холста, холст не затемняется. Пока на холсте остаётся ≥ 480 px, содержимое **сдвигается влево и сжимается** (колонка чата прижимается к левому краю — 760 при обычном Листе; при широком сжимается до 480; доска получает горизонтальную прокрутку), поэтому Лист ничего не закрывает. Когда места меньше 480, Лист ложится поверх без сдвига. Композер сжимается вместе с холстом.

### 2.4. Сворачивание и узкое окно

| Ширина окна | Строка офисов | Лист | Холст |
|---|---|---|---|
| ≥ 1280 | вкладки 176; справа всё в текстовом виде | 520 / 920 | остаток |

**1 офис.** Полоса офисов превращается в заголовок «Приложение ● работает»: вкладка одна, показывать её как вкладку не нужно; рядом `[+]`. Удобно до 6–7 вкладок.

## 3. Проход по сценариям

Шаг = клик, клавиша или отправка сообщения от «владелец видит каркас офиса A» до завершения действия. «Сейчас» — оценки из scenarios.md; «станет» — расчёт по этому документу.

### С1. Поставить задачу и следить

1. Композер в фокусе (после открытия офиса). Написать и отправить — **1**. Карточка задачи появляется в чате чипом и обновляет статус сама («следить» не требует перехода).
2. Увидеть на доске: `⌘\` (или `B`) — **2**; новая карточка подсвечена и помечена «новая».
3. Открыть карточку: клик — **3** (по желанию).

Из режима «Доска»: написать и отправить — **1**; карточка появляется подсвеченной сама, режим не меняется.

| Сейчас | Станет |
|---|---|
| ≈ 4–7 (сегмент «Чат» → чат → написать → отправить → «Доска» → найти → дровер) | **1** — поставить и следить в чате; **2** — найти на доске |

### С2. Ответить на вопрос / согласовать

1. Вопрос из своего офиса — карточка в чате (это та же запись «Ждёт меня», а не отдельная): нажать вариант — **1**. Если в чате не видно: `⌘I` — **1**, вариант — **2**.
2. Вопрос чужого офиса: вкладка с бейджем, тост «Лендинг · Design: согласуйте макет» с кнопками. Кнопка тоста — **1**; или `⌘I` — **1** → «Принять» — **2**. Переходить в офис не нужно.
3. Согласование с правками: `⌘I` → «Правки…» → поле → `Enter` — **3**.
4. Разрешение инструмента: в активном офисе модалка, «Разрешить» — **1**; в чужом — тост/запись, **1–2**.

| Сейчас | Станет |
|---|---|
| ≥ 4 (бейдж → «Жизнь офиса» → вкладка вопросов → ответ; разрешение — модалка, блокирует всё) | **1–2** |

### С3. Понять, что происходит

1. Свой офис: режим «Доска» — строка «Сейчас» (кто что делает) и колонки; **0** (одно переключение `B`, если был чат — **1**).
2. Чужие офисы: бейдж и точка видны постоянно (**0**); сводка «что делает» — наведение на вкладку (**0 кликов**, 1 наведение) или «Все офисы ▾» (**1**).
3. Сцена «Офис» — по настройке режимом (1) или Листом `O` (1).

| Сейчас | Станет |
|---|---|
| 3+ (сцена → доска → лог/«Жизнь офиса») | **0–1** |

### С4. Несколько офисов параллельно

1. Перейти: клик по вкладке или `⌘2` / `Ctrl+Tab` — **1**. Режим, чат, прокрутка, открытый Лист офиса, раскрытые группы доски, черновик композера — на месте.
2. Вернуться: **1**, всё снова на месте.
3. Ответить в чужом — без перехода (С2).

| Сейчас | Станет |
|---|---|
| 1 клик, но вид сбрасывается в «Офис»; карточка, дифф, группы, черновик теряются; клавиши нет | **1 / 1**, место сохранено, клавиши `⌘1–9`, `Ctrl+Tab` |

### С5. Разобрать вставшую или провалившуюся работу

1. Сорванная/вставшая задача — запись «Ждёт меня» с причиной: «T-7 сорвана: лимит плана, сброс в 18:20» и кнопками «Перезапустить после сброса», «Открыть». Вкладка офиса — красная точка.
2. `⌘I` — **1** → «Открыть» — **2** → Лист «Задача» с блоком «Что случилось» (причина, последние события, состояние слияния) и действиями: «Перезапустить», «Переназначить…», «Переформулировать» (подставит задачу в композер), «Снять» — **3**.
3. С доски/из чата: клик по карточке — **1** → «Что случилось» + действие — **2**.
4. Полный лог — ссылка «Ход работы по задаче →» внутри Листа (**+1**, Лист заменяется с «←»).

| Сейчас | Станет |
|---|---|
| ≈ 4–6 (доска → карточка → дифф; причина — лог/очередь/чат) | **2** из доски/чата, **3** из «Ждёт меня» |

### С6. Посмотреть результат

1. Чип задачи в чате / карточка на доске — клик — **1** → Лист «Задача» → блок «Результат» (документ открывается в Листе с «←», макет Figma/Penpot — ссылкой) — **2**.
2. «Принять» / «Вернуть с правками…» — там же — **3**.
3. Через «Документы»: `D` — **1** → документ — **2** → «Текст/Просмотр» — **3**.

| Сейчас | Станет |
|---|---|
| 3–4 | **2** (3 — вместе с решением) |

### С7. Выпустить версию

1. Запись «Ждёт меня»: «Выпуск 0.13.0 (minor): 5 фич» с кнопками «Выпускай», «Не сейчас», «Что войдёт →». `⌘I` — **1**, «Выпускай» — **2**.
2. Убедиться, что выпуск состоялся: запись меняется на статусную «Публикуется… → Вышел ✓» (в «Ждёт меня», после чего закрывается); полный вид — `R` — **1** (3 вкладки как сейчас).

| Сейчас | Станет |
|---|---|

1. `T` — **1** → сотрудник в списке — **2** → вкладка «Бриф» — **3** → «⋯» › «Экспорт пакета» — **4**.

## 5. Состояния и правила

### 5.1. Что с чатом и доской, пока открыт Лист

- Режим и содержимое холста **живые**: сообщения приходят, карточки меняются; новые сообщения ниже окна — «↓ 3 новых».
- Холст сжимается, а не закрывается (§2.3); при < 480 Лист ложится поверх.
- Композер всегда работает: сообщение уходит менеджеру активного офиса; Лист при этом не закрывается.
- Переключение режима (`⌘\`, `B`, `Enter`) **не закрывает** Лист: Лист «Задача» можно держать, листая чат и доску.
- Лист запоминается за офисом (кроме глобальных, §1.2); при смене вкладки показывается Лист нового офиса или ничего.
- **Открытие** нового раздела заменяет Лист; «←» возвращает на предыдущий в этой цепочке; вглубь внутри Листа — тоже «←».
- **Закрытие** — Esc (закрывает Лист целиком, не шаг), ✕, клик по пустому месту холста. Клик по интерактивному элементу холста (карточка, чип, ссылка) закрывает Лист и выполняет действие (чаще — открывает другой Лист). Если в Листе несохранённая форма, Esc/клик по холсту показывают внутри Листа «Сохранить / Отбросить / Остаться».
- Esc в режиме без Листа ничего не делает («выхода на главный экран» нет).
- Повтор клавиши раздела при открытом разделе закрывает Лист (`E`, `E`) — одно правило для всех.
- `Enter` вне поля: режим «Чат» + фокус композера; открытый Лист остаётся.
- Модалка разрешения: Esc/«Отложить» = запись остаётся в «Ждёт меня», агент ждёт, как и раньше.

### 5.2. «Ждёт меня»: состав, порядок, закрытие

| Что входит | Действие на месте |
|---|---|
| Запрос разрешения инструмента (закреплён сверху) | Разрешить / Запретить |
| Вопрос `ask_owner` (варианты 2–4 + «Своими словами») | кнопка варианта / поле |
| Согласование (макет, исследование, документ) | Принять / Правки… / Открыть |
| Сорванная или вставшая задача (лимит, слияние, ревьюер) | Перезапустить / Открыть / Снять |
| Вопрос о выпуске | Выпускай / Не сейчас / Что войдёт → |
| Предложение офиса (инициатива, правило, настройка) | Применить / Нет / Подробнее |
| Нет провайдера / ошибка окружения | Выбрать / Открыть настройки |

Порядок: разрешение → сорванная → вопрос → согласование → выпуск → предложение; внутри — по времени. Закрытие: ответом; «Позже» (1 час / до завтра) переносит в «Отложено» и снимает с числа; запись, на которую уже ответили в другом месте (чат, другой клиент), исчезает сама. Если записей ≤ 7 — плоский список, больше — группировка по офису. Число на кнопке и вкладках — только записи, требующие ответа (без отложенных).

### 5.3. Уведомления из других офисов

| Канал | Когда | Правило |
|---|---|---|
| Бейдж и точка на вкладке | всегда | число «ждёт меня», красная точка — разрешение или ошибка, жирное имя — непрочитанное в чате |
| Кнопка «Ждёт меня N» | всегда | сумма по всем офисам; клик — `⌘I` |
| Тост | событие, требующее владельца | не больше 3 одновременно, 8 с, разрешение — пока не отложено; для активного офиса не показывается, если запись видна на экране (карточка в чате) |
| Звук / системное уведомление | разрешение; окно без фокуса | настраивается; по умолчанию звук только для разрешения |
| «Не беспокоить» | вкладка → меню | тосты и звук офиса отключены, бейдж и запись остаются |
| Значок приложения / заголовок окна | окно без фокуса | сумма «ждёт меня» |

Ответ на запись другого офиса — на месте; вкладка при этом не переключается.

### 6.4. Слабые места (честно)

1. **Чат и доска не видны вместе.** Для владельца с одним офисом и диалогом «пишу — смотрю на доску» C хуже A. Смягчение: чип задачи в чате живой, строка «Сейчас». Полностью не лечится.
2. **Один Лист за раз.** Нельзя держать рядом лог и задачу; разбор сбоя — «←» туда-обратно. Широкий Лист (920) на 1280 оставляет холсту 360 — по сути полноэкранная страница.
3. **«Ждёт меня» не виден постоянно.** Чтобы увидеть суть записи, нужно открыть Лист (в B Входящие на экране). Спасают тосты и карточка в чате; без них — один клик.
4. **Чужие офисы на 5+.** Видны точка и число; «что делают» — только при наведении или в «Все офисы ▾». Для тех, кто ведёт 5+ офисов постоянно, B лучше.
5. **Рабочее за «Разделы ▾».** Документы, Расходы, Лог — второй клик; без привычки не найдут. Видимый вход один выпадающий список.
6. **Рабочее и редкое — в одной форме.** Лист не различает «часто / редко»; слой читается только по порядку в меню.
7. **Строка офисов перегружена на узком окне.** До 13 элементов: вкладки, сегмент, «Ждёт меня», пауза, шкала, `⌘K`, «Разделы»; на 900–1023 часть слита в `⋯`.
8. **Вкладки обещают закрытие.** Закрыть вкладку нельзя (только «Архивировать…»); язык и меню должны это объяснять, иначе ожидание браузера не совпадёт.
9. **Клик по холсту закрывает Лист.** Риск случайного закрытия; смягчено защитой несохранённой формы и тем, что по интерактивному элементу действие выполняется.
10. **Команда — 3–4 шага,** глубже цели.
11. **Сцена вторична.** По умолчанию Лист; чтобы была главным экраном, надо включить режим «Офис» — тогда сцена и чат не видны вместе.
12. **Числа шагов** — расчёт, не замер: проверять прогоном на макете.
