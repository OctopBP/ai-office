## Правки по замечаниям владельца (раунд 2)
1. **Колонки задач не трогаем.** Меняется только хедер блока (ряды A–C). Ряд D в макете — лишь заглушка «как сейчас»: три строки текста стоят вместо существующих колонок `.task-cols` / `TaskColumnBlock`, их вид, состав и поведение остаются прежними. Реализация D не меняется.
2. **Вернулся прогресс по задачам.** Раньше в заголовке фичи стояли счётчики `GroupCount` (значок + число; только ненулевые): в работе ◔, очередь ◷, провал, готово ✓, снято, и справа стоимость `$0.00`. В первой версии макета их не было, остался только «N из M». Теперь в правой части шапки: «N из M» + счётчики + стоимость, одной строкой, выровнено вправо (в макете — один текстовый слой «Прогресс», у «закрыта» — «3 из 3 ✓ 3 $1.20»). Чип статуса сдвинут влево (x=306), чтобы освободить место. Подсказки-title у счётчиков — как в `Board.tsx` (`board.group.*`).
3. Заодно: исправлены сбитые позиции «Названия» в вариантах `254:479` и `254:527`, скругление чипов статуса (10) и кнопок «Снять» (6).

Ряды в каждом фрейме: A Шапка (шеврон, F-N, название, чип, «N из M»), B Подшапка (триггер описания, подсказка, кнопки), C Описание (только в развёрнутых), D Тело (заглушка колонок задач, не меняется).

## Не сделано
- Не настоящие компоненты/варианты (см. выше).
- Только светлая тема, цвета — приближённые hex, не токены.
- Счётчики и стоимость — одним текстом с глифами ◔ ◷ ✓ вместо иконок Icon; цвета счётчиков (ok/fail) не раскрашены. Без стрелок ↑↓, чипа «инициатива», подтверждения «Снять».
- Скриншот проверки не просмотрен (ответ моста превысил лимит): расположение слоёв проверено только по данным get_node.
- В шапке и у чипа/кнопки «Снять» радиус скругления у части узлов 0 (у «Запустить» 6).
