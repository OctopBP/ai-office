# T-349. Доска: вкладки «План» и «Задачи» в одну

Статус: только текстовая спека, Figma не открывалась (прошлая попытка T-347 упёрлась в предохранитель расхода). Фреймы в Figma рисуются отдельной задачей по этому тексту. Код не менялся.

Источник: `src/web/Board.tsx` (`Board`, `groupTasks`, `TaskGroupBlock`, `EpicRow`), `src/web/styles/board.css`, `src/web/store.ts` (`taskGroupsOpen`, `boardEpic`), словари `src/web/i18n/ru.ts`/`en.ts`.

## 1. Что меняется

Сейчас на доске три подвкладки: «Направления», «План», «Задачи». План — это список `EpicRow` (фича, статус, прогресс, цель, «Поехали», «Снять», ↑↓, фильтр), а «Задачи» — те же фичи группами `TaskGroupBlock` с колонками задач. Одна и та же фича показана дважды.

Станет две подвкладки: **«Направления»** и **«Задачи»**. Всё, что умел `EpicRow`, переезжает в шапку и подшапку группы фичи на вкладке «Задачи».

## 2. Структура вкладки «Задачи»

Сверху вниз внутри `.board-pane`:

1. **Полоса вкладок** `.board-tabs`: сегмент `Направления | Задачи`; справа приглушённая подпись `plan.focus` («одновременно ведём фич: N») — переехала из заголовка «Плана».
2. **Живые группы фич** — `planned` и `active`, порядок **как в плане** (`epic.order` по возрастанию; именно он решает, что офис возьмёт следующим).
3. **Группа «Разное»** (`board.group.misc`) — задачи вне плана (`epicId` пуст или фича исчезла). Всегда после живых фич и перед историей. Показывается, только если в ней есть задачи. Без кнопок «Запустить»/«Снять», без статуса и номера.
4. **История** — `done` и `cancelled`, внизу, новые сверху (как сейчас `newestEpicFirst`), по умолчанию свёрнуты и приглушены.

Отличие от текущего `groupTasks`: (а) живые группы сортируются по `order`, а не «новые сверху»; (б) **фичи без задач больше не скрываются** (`.filter(g => g.total > 0)` убрать для фич; для «Разного» оставить) — иначе фича, ждущая согласия и ещё не получившая задач, пропадает вместе с кнопкой «Запустить».

## 3. Анатомия блока фичи (`.task-group`)

Контейнер: рамка 1px `--board-line`, радиус `--radius-card` (12px), фон `--surface`, `overflow: hidden`. Между блоками `--space-2` (8px).

Блок состоит из четырёх рядов:

### Ряд A. Шапка (`.task-group-head`) — как сейчас
Фон `--board-plate`, padding `--space-2` `--space-3` (8/12), шрифт `--fs-row` 500. Слева направо:
- шеврон ▸/▾ 16px (`--ink-3`) — показывает, раскрыт ли **список задач**;
- номер `F-N` (`<b>`, бейдж; цвет по статусу: active — `rgba(var(--accent-rgb), .14)` / `--accent`, done — `rgba(var(--ok-rgb), .14)` / `--ok-ink`, прочие — как сейчас);
- название — одна строка, `text-overflow: ellipsis`, `title` = полное название; у done цвет `--ink-3`;
- чип статуса (§5), чип «инициатива офиса» (если `origin === 'office'`, `plan.initiative`, `plan.initiativeHint` в `title`);
- справа: прогресс «N из M» (`plan.progress`, `--fs-small`, `--ink-3`), счётчики `GroupCount` (в работе, очередь, провал, снято — как сейчас), стоимость `$0.00` (`--board-money`, 600, только если > 0).
- стрелки ↑↓ (`.epic-move`, `.sq.mini`, ширина `--mini-h`) — только у `planned`/`active`; ↑ disabled у первой, ↓ у последней **среди всех фич плана** (логика `move` из `EpicRow` без изменений).

Шапка перестаёт быть одной `<button>`: вложенные кнопки (стрелки) недопустимы. Новая разметка: `div.task-group-head` с внутренней `button.task-group-toggle` (шеврон + номер + название + чипы, `flex: 1`, `aria-expanded`) и отдельной группой `.task-group-side` справа; стрелки лежат в `.task-group-side` вне toggle. Щелчок по toggle сворачивает задачи; щелчок по свободному месту шапки не должен «промахиваться» — toggle занимает всю ширину кроме `.task-group-side`.

### Ряд B. Подшапка фичи (`.task-group-sub`) — новый
Показывается у всех групп с фичей (у «Разного» нет). Padding `--space-1` `--space-3`, фон `--surface`, нижняя граница 1px `--hairline`, высота строки ≥ 28px, `--fs-small`. Слева:
- кнопка-ссылка описания «Описание фичи» + шеврон (§4). Нет `goal` — кнопки нет;

Справа (`margin-left: auto`, gap `--space-2`) — **действия** по таблице §6: «Запустить» (`.merge`, акцентная), «Снять» (`.mini`), либо подтверждение. Для статусов без действий справа пусто; если нет ни описания, ни действий — ряд B **не рендерится** (done/cancelled без цели).

Подпись-подсказка (приглушённая, `--ink-3`) слева от кнопок: у «ждёт согласия» — «ждёт вашего согласия» (`plan.awaiting`), у «в очереди» — «ждёт очереди» (`plan.queued`).

### Ряд C. Описание (`.task-group-goal`) — новый, §4
### Ряд D. Тело (`.task-group-body`) — колонки задач, как сейчас (`.task-cols`, `TaskColumnBlock`), padding `--space-2` `--space-3`.

Дополнительно: инициатива с `rationale` — строка `epic-rationale` (`plan.initiativeHint`) выводится внутри ряда C под целью, а не отдельно.

Тени, градиенты, новые цвета не вводятся — только токены из `tokens.css`: `--surface`, `--board-line`, `--board-plate`, `--hairline`, `--ink`, `--ink-3`, `--accent`, `--accent-rgb`, `--ok`, `--ok-rgb`, `--ok-ink`, `--board-money`, `--radius-card`, `--space-1..4`, `--fs-small`, `--fs-row`, `--fs-body`, `--mini-h`.

## 4. Описание фичи (сворачиваемое)

**Свёрнуто (по умолчанию):** виден только триггер в ряду B: «Описание фичи ▸» (`--accent`, `--fs-small`). Ряда C нет в DOM.

**Развёрнуто:** триггер «Описание фичи ▾», под подшапкой ряд C: padding `--space-2` `--space-3`, фон `--board-plate` с прозрачностью (`--film-2`), текст `epic.goal`, `--fs-small`, цвет `--ink-2`/`--ink`, `white-space: pre-wrap`, `overflow-wrap: anywhere`, максимальная ширина строки ~ 80ch.

**Длинное описание:** высота ряда C ограничена `max-height: 240px` с вертикальной прокруткой внутри (`overflow-y: auto`), чтобы одна фича не выталкивала остальные за экран. Короткое — по высоте текста. Скролл внутри — не двойной: если контент влезает, полосы нет.

**Запоминание:** состояние описания живёт в сторе, как `taskGroupsOpen`: `epicGoalOpen: Record<string, boolean>` + `setEpicGoalOpen`, ключ — `epic.id`. Живёт на время сессии, сбрасывается там же, где сбрасывается `taskGroupsOpen` (смена офиса, `store.ts:860,873`). На диск не пишем. Отсутствие ключа = свёрнуто. Состояние описания **не зависит** от того, раскрыты ли задачи, и наоборот.

Сворачивание списка задач (ряд D) остаётся как сейчас: ключ `taskGroupsOpen[group.key]`, по умолчанию открыто, если есть `running + review + queued > 0`, иначе закрыто.

Доступность: триггер — `<button aria-expanded aria-controls>`, ряд C — `role="region"`.

## 5. Статус фичи и прогресс

Чип статуса (`.chip`) — единый вывод `epicState(epic)`:

| Состояние | Условие | Подпись (ru) | Подпись (en) | Ключ |
|---|---|---|---|---|
| Ждёт согласия | `planned` и `!approved` | ждёт согласия | awaiting approval | `plan.status.awaiting` (новый) |
| В очереди | `planned` и `approved` | в очереди | queued | `plan.status.queued` (новый) |
| В работе | `active` | в работе | in progress | `plan.status.active` |
| Закрыта | `done` | готова | done | `plan.status.done` |
| Снята | `cancelled` | снята | dropped | `plan.status.cancelled` |

(Раньше «ждёт согласия» и «в очереди» оба были «в плане»; различались только подписью ниже. Теперь различаются чипом.) Цвета чипов: «ждёт согласия» — янтарный `--accent-6`; «в очереди» — нейтральный `--accent-muted`; «в работе» — `--accent`; «готова» — `--ok`; «снята» — нейтральный, зачёркнутого текста нет.

**Прогресс** «N из M» (`plan.progress`): N — `group.done` (задачи, закрытые по `taskClosed`), M — `group.total`. Считается в `groupTasks`, отдельного счётчика на сервере нет. Если `M = 0` — вместо «0 из 0» пишем «задач пока нет» (`board.group.noTasks`, новый). У «Разного» прогресс не показывается (нет цели, нечего «закрывать»).

## 6. Кнопки «Запустить» и «Снять»

Кнопка «Запустить» — прежняя «Поехали» (`approveEpic`); ключ `plan.approve` получает подпись «Запустить»/«Launch». «Снять» — `cancelEpic`.

| Статус фичи | «Запустить» | «Снять» | Подсказка слева | ↑↓ |
|---|---|---|---|---|
| Ждёт согласия (`planned`, `!approved`) | **видна**, акцентная (`.merge`) | видна | «ждёт вашего согласия» | да |
| В очереди (`planned`, `approved`) | нет | видна | «ждёт очереди» | да |
| В работе (`active`) | нет | видна | — | да |
| Закрыта (`done`) | нет | нет | — | нет |
| Снята (`cancelled`) | нет | нет | — | нет |
| «Разное» (вне плана) | нет | нет | — | нет |

**Подтверждение «Снять»** (как в `EpicRow`, inline, без модалки): по клику «Снять» в подшапке вместо кнопки появляется `Снять фичу с плана?` (`plan.dropConfirm`, `--ink-3`) + красная `«Снять»` (`.stop`, `plan.dropYes`) + `«Отмена»` (`.mini`, `common.cancel`). «Снять» без подтверждения не работает. Подтверждение сбрасывается по «Отмена», по Esc и при смене статуса фичи. Текст предупреждения дополняется пояснением в `title` красной кнопки: «Нераздатые задачи фичи не запустятся». Состояние подтверждения локальное (`useState` в блоке фичи).

«Запустить» подтверждения не требует (обратимо: фичу можно снять).

Пока идёт запрос (кнопка нажата), обе кнопки `disabled` до обновления статуса приходящим событием.

## 7. Все состояния блока (для фреймов)

Каждое — отдельный фрейм/вариант, светлая и тёмная тема:

1. **Ждёт согласия, задач нет** — чип янтарный, «задач пока нет» вместо прогресса, подшапка: «Описание ▸», подсказка, «Запустить», «Снять». Тело: приглушённая строка `board.group.noTasks`.
2. **Ждёт согласия, есть задачи** (запланированные) — то же, тело с колонками, свёрнуто по умолчанию (нет живых).
3. **В очереди** — чип нейтральный, только «Снять».
4. **В работе, раскрыта** — счётчики в шапке, колонки в теле, «Снять».
5. **В работе, описание развёрнуто** — ряд C виден.
6. **Подтверждение снятия** — inline-вариант подшапки.
7. **Закрыта (done)** — приглушена (opacity .55), свёрнута, без действий, прогресс «M из M».
8. **Снята (cancelled)** — приглушена, свёрнута, без действий.
9. **Длинное описание** — ряд C с `max-height 240px` и скроллом.
10. **Нет описания** — триггера «Описание фичи» нет.
11. **Инициатива офиса** — чип + `rationale` в ряду C (триггер описания показывается, даже если `goal` пуст, но есть `rationale`).
12. **Разное** — шапка без номера, без чипа, без подшапки.
13. **Название длинное** — многоточие, `title`.
14. **Фокус-обводка** (пришли из чата, §9) — `box-shadow: 0 0 0 2px var(--accent)`, 2 секунды.

**Пустое состояние вкладки:** нет ни фич, ни задач — прежний `board.empty` («Пусто. Поставьте задачу PM’у справа.»). Есть фичи без задач — блоки рисуются (состояние 1). Есть только задачи вне плана — одна группа «Разное».

## 8. Судьба вкладки «План»

**Удаляется.** `BoardTab = 'directions' | 'tasks'`, `BOARD_TABS` без `plan`, ключ `board.tab.plan` удаляется из обоих словарей. Остаётся вкладка по умолчанию — «Задачи». Блок `.plan`/`.plan-rows`, компонент `EpicRow` и стили `.epic*` удаляются после переноса (`.plan-head` остаётся: им пользуется «Направления»). Заголовок «План» (`plan.title`) уходит; `plan.focus` переезжает в полосу вкладок.

**Фильтр по фиче** (`only`, `epic-pick`, «Показать все» `plan.showAll`) уходит: при группировке по фичам он дублирует сворачивание. Вместо него — **переход по просьбе из чата** (`boardEpic`): ставим вкладку «Задачи», раскрываем группу (`setTaskGroupOpen(id, true)`), `scrollIntoView({block:'center'})` и подсвечиваем обводкой на 2 секунды (состояние 14), после чего гасим `boardEpic`.
