# T-123: доска задач — доработки по обновлённому макету

Макет — Figma «Office», узел `188:887` (снимки: `figma-188-887.png` — весь
кадр, `figma-card-done.png` — карточка ×4, `figma-feature-head.png` — шапка
развёрнутой фичи). Значения сняты заново через Figma MCP Bridge (`get_node`
по всему дереву кадра), высоты перепроверены по пикселям снимка ×4.
Прежняя таблица — `docs/design/T-121/README.md`; в ней часть значений была
заменена ближайшим токеном, здесь — точные.

Макет нарисован только в тёмной теме. В тёмной стоят ровно цвета макета
(токены `--board-*` в `[data-theme='night']`), в светлой — их смысловые
двойники из светлой палитры (см. последний столбец).

## Главное, что поменялось в макете

1. **Колонка стала подложкой**: фон `#1b1c1e`, радиус 12, поля 12/8, шаг 12.
   В main колонка была без фона.
2. **Карточка лежит темнее колонки**: фон `#111214` (тело фичи), радиус 8.
   В main — плёнка поверх, радиус 10.
3. **Обрезанный интерлиньяж**: у текста в макете включена обрезка
   по вертикали (Figma «vertical trim», от прописной до базовой линии). Отсюда
   высоты текстовых слоёв 7/9/23 и чип высотой 15. В CSS это
   `text-box: trim-both cap alphabetic`.
4. Подписи: колонка «План», в чипе «план» и «провалено».
5. Денег на карточке в макете нет.

## Новые токены (`src/web/styles/tokens.css`)

- `--fs-row: 12px` — кегль строки фичи; `--fs-body` (12.5) сюда не подходит.
- `--radius-tile: 8px` — карточка и чип на доске.
- `--board-plate`, `--board-col`, `--board-chip`, `--board-line`,
  `--board-title`, `--board-col-name`, `--board-money`, `--board-work`,
  `--board-fail`, `--board-drop`, `--board-done`: в ночной теме — точные цвета
  макета, в дневной — ссылки на токены светлой темы.

Своими числами с комментарием, без токена, заданы только шаг 38 (название ↔ счётчики),
шаг 2 (значок ↔ число) и портрет 12 со скруглением 2.

## Что не удалось сделать точно

- **`text-box` в Firefox не поддерживается** (Chrome/Electron 133+, Safari 18.2+
  поддерживают). В Firefox строки карточки будут на 1.5–4 px выше, чем в макете,
  но сломается только вертикальный ритм, раскладка останется целой.
- **Высота карточки 87.8 вместо 87**: Figma округляет обрезанную строку
  (прописная Inter 10 — 7.27) до 7, а браузер нет.
- **Счётчики в шапке**: в макете у F-3 стоят «в работе 1, провалено 3, готово 5,
  снято 5», хотя в колонках 2 в работе, 6 готовых и 2 провала, а колонки «Снято»
  нет. Судя по этому, числа в шапке — заполнитель. Правило подсчёта осталось
  прежним: считаем по задачам, и значок очереди (песочные часы) сохранён, хотя
  в макете его нет.
- **Сравнение рендера со снимком не картинкой**: headless Chrome в песочнице
  исполнителя не запускается («Failed to create socket directory»). Проверка
  была такой: SSR-сборка доски на тестовых данных (как в T-121). По ней сверены
  структура, умолчания сворачивания, подписи ru/en, классы чипов и отсутствие
  денег на карточке. Размеры пересчитаны по CSS вручную (строка выше).
