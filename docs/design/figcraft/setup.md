# figcraft у дизайнера: что сделать владельцу

figcraft — открытый клон Figma на Rust (MIT или Apache-2.0, альфа 0.5.1). Мы
пробуем его **пилотом рядом с Penpot**, Figma он не заменяет. Разбор и план
пилота — документ офиса D-4, раздел 7 (это задача FC-1).

В каталоге MCP офиса (`src/server/mcp.ts`) есть сервер `figcraft`:

```
figcraft-cli mcp --no-system-fonts
```

Это stdio: офис сам запускает CLI на каждую сессию дизайнера. Окно figcraft,
плагин и ключи не нужны — движок работает внутри процесса (headless).
`--no-system-fonts` берёт только встроенные шрифты, так что макет рендерится
одинаково на любой машине.

По умолчанию сервер **никому не подключён**: на время пилота его включают
дизайнеру вручную, галочкой.

## 1. Поставить figcraft-cli

1. Открыть релизы: <https://github.com/storytold/figcraft/releases>, релиз
   **v0.5.1**, скачать `figcraft-cli-0.5.1-macos-universal.zip` (~77 МБ).
2. Распаковать. В папке `figcraft-cli-0.5.1-macos-universal` лежит бинарник
   `figcraft-cli` и лицензии шрифтов.
3. Положить бинарник в каталог из `PATH`, например:

   ```sh
   mkdir -p ~/.local/bin
   cp ~/Downloads/figcraft-cli-0.5.1-macos-universal/figcraft-cli ~/.local/bin/
   chmod +x ~/.local/bin/figcraft-cli
   ```

   Если `~/.local/bin` ещё нет в `PATH`, добавить в `~/.zshrc` строку
   `export PATH="$HOME/.local/bin:$PATH"` и открыть новый терминал. Подойдёт и
   `/usr/local/bin` или `/opt/homebrew/bin`.
4. Проверить в новом терминале:

   ```sh
   figcraft-cli --version   # должно напечатать: figcraft-cli 0.5.1
   ```

   Бинарник подписан разработчиком (Team ID `DJ6XS33FX8`). Если macOS всё же
   откажется его запускать («не удаётся проверить разработчика»), снять
   карантин, который браузер ставит на скачанное:
   `xattr -d com.apple.quarantine ~/.local/bin/figcraft-cli`.

CLI сам не обновляется: версию фиксирует бинарник, который вы положили. Новый
релиз — только заменой файла, и лучше по решению пилота: формат и команды
figcraft меняются от релиза к релизу.

## 2. Включить сервер дизайнеру

1. Убедиться, что сервер есть в каталоге и не выключен: **Настройки →
   Инструменты**, строка **FigCraft**. Офис, заведённый раньше, получает
   её сам — каталог доливает новые умолчания.
2. Открыть роль дизайнера, блок **«Внешние инструменты»**, поставить галочку
   **FigCraft**. Остальные галочки (Figma, Figma Console, Penpot) не трогать —
   пилот идёт параллельно.

Сервер подключается со следующей сессии дизайнера; уже идущую задачу это не
меняет.

## 3. Проверить, что сервер подключился

Статус приходит от живых сессий, поэтому сначала дайте дизайнеру любую задачу
(например, пилотный макет FC-2). Затем в **Настройки → Инструменты** у строки
**FigCraft** должен стоять статус **«подключён»** (`connected`).

- **«не подключился»** (`failed`) — офис не нашёл `figcraft-cli`. Чаще всего
  это `PATH`: приложение офиса для macOS запускается не из терминала и может
  не видеть каталог, добавленный только в `~/.zshrc`. Положите бинарник в
  `/usr/local/bin` (или `/opt/homebrew/bin`) и перезапустите офис. Если не
  помогло — в каталоге (Настройки → Инструменты → FigCraft) вместо
  `figcraft-cli` указать полный путь к бинарнику.
- **«пока неизвестно»** — ни одна сессия с сервером ещё не запускалась.

Проверить сервер руками без офиса можно так (ответ — строка JSON с
`"name":"figcraft"`):

```sh
printf '%s\n' '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"check","version":"0"}}}' \
  | figcraft-cli mcp --no-system-fonts
```

## 4. Что помнить

- **«Share ▸ Online» макеты офиса не отправлять.** Эта кнопка загружает файл
  на `collab.craftapps.dev`, и, как прямо пишут авторы, **без сквозного
  шифрования**. Файл видит сервер чужого проекта. «Share ▸ Local network» тоже
  без шифрования. Если нужен совместный просмотр — только свой
  `figcraft-server`.
- **У сервера нет периметра записи.** `save_file` и `export` с `path` пишут
  куда угодно на диске. Поэтому офис считает их записью и спрашивает по
  правилам разрешений, а дизайнеру велено писать только внутрь рабочей копии.
  `screenshot` и `export` без `path` (картинка возвращается в ответ) —
  чтение, без вопроса.
- **Это альфа.** Падения, смена команд и формата `.figcraft` между релизами —
  ожидаемы. Реальные `.fig` из Figma ещё не проверены (это задача FC-3).
