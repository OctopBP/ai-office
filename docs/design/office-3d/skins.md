# Скины: внешности агентов и стенд

Внешность агента — это скин персонажа Kenney «Animated Characters
Protagonists»: png 1024×1024 в `design/models/characters/skins/`. Список
внешностей — `looks.json` в той же папке. Этот документ — про то, почему
список лежит там и как им управляют.

## Файл и список

Комната берёт текстуры из папки целиком (`import.meta.glob` в
`Agents3D.tsx`), а форма роли предлагает только то, что записано в списке.
Запись — это имя файла, спрайт плоского офиса и подпись на каждом языке:

```json
{ "id": "boris", "sprite": "agent_p10", "title": { "ru": "Бородач в фиолетовом", "en": "Beard in purple" } }
```

Раньше список был массивом в `src/shared/looks.ts`, а подписи — ключами
`look.<id>` в словарях веба. Три места на одну внешность, и все три — код.
Инструмент, который добавляет скин, должен был бы править исходники, а это
не то, что стоит уметь дев-серверу. Теперь список — данные, разбор со схемой
(`src/shared/look.ts`) один на веб, плагин vite и тест.

Подпись живёт при скине, а не в словаре интерфейса, по той же причине, по
какой у пресетов, заведённых руками, название своё: её заводит художник
вместе с файлом, а не переводчик вместе с релизом.

## Стенд

```bash
npm run dev:3d
```

Дальше `http://localhost:5174/?skins=1`.

Слева все файлы папки стоят в ряд в одной позе; поза переключается кнопкой,
включая переходы (садится, встаёт). Фигура, клипы и материал — те же, что в
комнате (`buildRig`, `skinMaterialOf`), рост — из `fit.json`. Табличка над
фигурой пунктиром — файл есть, в списке нет.

Справа — карточки, по одной на файл, в порядке списка (это же порядок в форме
роли). В карточке — подписи, спрайт плоского офиса, порядок, замена и удаление
файла. Внизу — записи, у которых файла нет.

Файлы пишутся сразу: положить, заменить и удалить — это действия над диском,
и «отменить» у них нет (удаление спрашивает). Список — кнопкой «Сохранить»:
он один на все скины, а перезагружать страницу на каждую букву подписи
незачем. Черновик списка переживает перезагрузку, которую vite устраивает
после правки файлов в папке.

## Маршруты дев-сервера

Плагин `skinsBench` в `vite.config.ts`, только в `serve`:

| | |
|---|---|
| `GET /__skins` | файлы (габарит, размер, время) и список как есть |
| `GET /__skins/file/<id>.png` | файл без кеша |
| `PUT /__skins/file/<id>.png` | положить или заменить; тело — png |
| `DELETE /__skins/file/<id>.png` | удалить и вычеркнуть из списка |
| `PUT /__skins/registry` | записать список |

Список перед записью проходит схему и сверяется с папкой: запись без файла не
записывается. Имя файла — `^[A-Za-z0-9][A-Za-z0-9_-]*$`, оно попадает в путь.

## Проверка

```bash
npm run test:looks
```

Запись без файла — ошибка, файл без записи и пустая подпись —
предупреждение.
