# Критерии T-756

Источник: бриф T-756. Проверка только текущего приложения через MCP browser; без изменения настроек и процессов.

1. Проверить доступное подключение; подтвердить офис по T-726/T-730/T-737/T-742 и отображаемый/сохранённый reviewer.spendFuseTokens (4 = 4_000_000) либо точно зафиксировать техническую недоступность.
2. В пределах доступного UI проверить установленную версию/обновление и роль/дату остановки verify T-726; отделить непроверенное от наблюдений и старого порога 2_195_000.
3. Составить краткий отчёт с доказательством и следующим шагом для PM; настройки, ревью, запуски и процессы не изменять.

## Матрица «устройство × сценарий»

| Устройство | Сценарий | Ожидаемый результат |
|---|---|---|
| Текущее окружение MCP, 1440×900, DPR 2, альбом, онлайн | Доступное подключение | Приложение доступно либо записан точный адрес и ограничение инструментов |
| То же | Офис и лимит | Подтверждение UI либо явная отметка недоступности |
| То же | Версия и verify T-726 | Наблюдения UI либо явная отметка недоступности |

Отдельная проверка мобильных устройств и тем не входит в узкую задачу.
