# Критерии: T-701 — вложения в чате с менеджером

1. Скрепка: один и несколько файлов прикрепляются чипами к реплике.
2. Перетаскивание файла на чат: подсветка зоны, файл прикрепляется.
3. Перетаскивание файла мимо чата не открывает его в окне вместо приложения.
4. Вставка картинки из буфера прикрепляет её.
5. Удаление чипа снимает вложение.
6. Файл больше 20 МБ и 11-й файл — понятная ошибка.
7. Отправка только вложения без текста проходит.
8. В истории видны картинка и текстовый файл; после перезагрузки страницы они на месте.
9. Картинка в истории открывается по клику.
