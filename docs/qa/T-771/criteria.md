# Критерии T-771

Источник: бриф T-771 и docs/отчёт-T-769.md. Проверяется только блок двух рядов 5h/1w. Код, данные и окружение не изменяются.

1. До визуальных проверок подтверждено, что загруженное приложение содержит изменения T-769 (main: f147d0b), либо записан конкретный BLOCKED. История рабочей копии сама по себе не подтверждает загруженную версию.
2. Для обеих строк hover открывает подсказку; переход указателя к плашке сохраняет её, уход закрывает; клавиатурный focus открывает, Escape закрывает, фокус виден.
3. Подсказки показывают доступные реальные данные: провайдер, процент, отсчёт, точное локальное время сброса с поясом. Отсчёт открытой подсказки обновляется примерно раз в 30 секунд.
4. В обеих темах блок и подсказки читаются; при узком/свёрнутом рейле и масштабе 200% нет обрезания или перекрытия. Длинные суммы проверяются только при наличии реальных данных.
5. Каждый сценарий получает PASS/FAIL/BLOCKED с основанием; недоступные состояния и конкретные дефекты перечислены отдельно. Снимки — только блока рейла, без фиктивного подтверждения недоступного UI.
