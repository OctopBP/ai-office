## Запуск после слияния в main

Из корня проекта с уже установленными зависимостями:

```sh
node scripts/preview-рейла.mjs
```

Ожидаемый URL: `http://127.0.0.1:5188/rail-preview.html`. Порт фиксированный; при занятости скрипт должен завершиться ошибкой. Остановка — Ctrl+C. Не использовать `npm run dev`: preview имеет собственную конфигурацию Vite без прокси и сервера офиса. Скрипт блокирует `/api`, `/ws`, `/` и `/index.html`. Точка входа не вызывает connect(), список офисов пуст, поэтому эффект RailSpend не запускает fetch/опрос. Язык сохраняется через существующий setLang в localStorage отдельного origin preview.

Сценарии выбираются в форме или параметром `scenario`: `full`, `unknown`, `partial`, `expired`, `noReset`, `long`, `stale`, `empty`, `loading`, `edges`. Они показывают соответственно полные данные, неизвестные цену/лимиты, частичную цену/историю, истёкший сброс, неизвестный сброс, длинные суммы, устаревший расчёт, отсутствие данных, переход с ожиданием, границы 0%/100%. Это фиксированные данные, а не воспроизведение сетевых ошибок. `loading` не завершается автоматически. `stale` проверяет возраст расходов, а не лимитов. `edge=right` не имеет реализации в сохранённом CSS и не заявляется доступным сценарием.

`lang=ru|en`, `theme=day|night`; например: `http://127.0.0.1:5188/rail-preview.html?scenario=partial&lang=en&theme=night`. Настоящие RailSpend и Tooltip подключены напрямую: наведение или Tab открывают подсказку, Escape закрывает (ожидание по коду, требует QA).

## ui-self-check (A–E, G), нормы ui-standards

- A — violated: сохранённые стили используют токены отступов/цветов/радиусов и продуктовый kit; но font-weight 500, ширина rail из shell.css, пиксельные кегли и отдельные значения исходного kit/Tooltip не полностью соответствуют строгому требованию «только tokens.css». Переработка продуктового кита вне задачи. В preview используются 4 кегля (12/12.5/13/15 px), 2 начертания (400/500); новые токены не предлагаются.
- B — violated (проверка неполная): по WCAG формуле (Lmax+0.05)/(Lmin+0.05) контраст ink-3/surface = 6.69 day, 7.25 night; ink-2/surface = 12.82/14.77; ink-2/canvas = 11.35/15.21; ink/canvas = 16.31/17.56. Три слабейшие из этих проверенных пар: day ink-3/surface 6.69, night ink-3/surface 7.25, day ink-2/canvas 11.35. Граница select — ink-3/surface ≥3, focus 2 px ink-2 ≥3; select/кнопка 32 px, строки RailSpend минимум 24 px по CSS. Неизвестность и состояния выражены текстом, Escape реализован в Tooltip. Полная проверка hover/pressed, нативных select и клавиатуры не проводилась. Унаследованный переход кнопки 120 мс не имеет локального reduced-motion override; оставлен исходным по ограничению объёма переноса.
- C — violated: перенесены существующие empty/loading/partial/full, unknown, long и edges. Сценария сетевой ошибки с повтором нет, disabled и 1000 элементов не воспроизводятся; не расширяли fixtures по задаче. Контролы и их визуальные состояния требуют QA.
- D — passed по коду: статус стенда виден; выход — закрыть вкладку/Ctrl+C; используются настоящие компоненты и существующие слова; разрушительных действий нет; сценарии подписаны, повтор — кнопкой. Реальные сетевые ошибки не имитируются, инструкция объясняет границу.
- E — passed по коду: тексты preview есть в ru/en; кнопка «Начать сценарий заново» содержит действие; пользовательских кодов ошибок нет. Соотношение длины всех переводов 20–30% не подтверждено; русская длинная строка и переполнение требуют QA.
- G — violated (проверка неполная): main/form/label/select/button/section семантические, строки настоящего компонента фокусируемы; форма переносится flex-wrap. Обе темы и 200% в браузере не проверялись по прямому запрету задачи; относительные размеры текста в исходных токенах не реализованы. Визуальный результат не считается подтверждённым.

Ничего дополнительно не проектировалось. Убран только пустой неиспользуемый CSS-файл из переноса.
