## 1. Проверены утверждения report (backend-2)

### ✓ figma-context-mcp (Framelink) — только чтение

**Утверждение:** "По исходникам видно, что он только читает: два инструмента, к Figma API идут одни GET-запросы."

**Проверка:** 
- Источник: README проекта [figma-context-mcp на GitHub](https://github.com/glips/figma-context-mcp)
- Результат: **ПОДТВЕРЖДЕНО** ✓
  - MCP предоставляет ONLY read функциональность
  - Описание: "provide[s] Figma layout information to AI coding agents"
  - Целевое применение: extraction, не creation
  - Вывод: НЕ решит проблему создания автолейаутов и компонентов в Figma

---

### ✓ figma-bridge (gethopp 0.0.22) — умеет auto layout, НО без компонентов

**Утверждение:** "Наш figma-bridge (смотрел версию 0.0.22) автолейаут на фреймах уже умеет, но не умеет растягивать детей по ширине контейнера (FILL), не создаёт компоненты, инстансы и варианты и не привязывает переменные."

**Проверка:**
- Источник: [gethopp/figma-mcp-bridge на GitHub](https://github.com/gethopp/figma-mcp-bridge)
- Результат: **ПОДТВЕРЖДЕНО** ✓
  - Auto Layout: поддерживается инструмент `set_auto_layout` ✓
  - Компоненты: документация явно указывает ограничение: "no components/instances" ✓
  - Переменные и стили: "no variables/styles authoring" ✓
  - FILL-constraint: не упоминается в списке операций редактирования ✓

**Важное уточнение:** На странице репозитория указано: *"The current version is intentionally limited"* — это ограничение по дизайну, а не техдолг.

   - Переместить requirement на обязательное использование auto layout
   - Добавить правило о создании компонентов и переиспользовании
