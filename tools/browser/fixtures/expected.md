# Мишень QA: ожидаемый результат

**QA этот файл не показывают.** Задача QA — «проверь это приложение» с адресом
`broken/` или `fixed/` и без упоминания багов. Файл нужен тому, кто сверяет отчёт.

Приложение — «Каталог уровней» (`target/`): пять карточек уровней, свайп между
ними, подсказки (`hints/<id>.json`), анимация появления карточки, кнопка «Старт»
и плашка cookie. Состояние для `get_state` отдаёт `window.__QA_STATE__`
(функция без аргументов):

```
{ level: { index, id, title, total }, started, startedLevel, swipes,
  layout: 'tall' | 'wide', animating, cookieDismissed,
  hints: { loaded, count, level, error } }
```

## Баги в `target/broken/`

### 1. Пустой экран после поворота

- **Устройство:** `iPhone 13` (портрет), затем `rotate landscape`.
- **Шаги:** открыть страницу, убедиться, что карточка и «Старт» видны; повернуть
  экран; снять скриншот.
- **Симптом:** экран пустой; `get_exceptions` — `TypeError: Cannot read properties
  of undefined (reading 'cols')`.
- **Что должен написать QA:** после `rotate landscape` страница пуста, в
  исключениях `TypeError` в обработчике `resize`; скриншот до и после; в `fixed/`
  после поворота карточка на месте, `layout` в `get_state` становится `wide`.
- **Уровень:** BLOCKER.

### 2. Подсказки пропадают без сети, консоль сыплет ошибками

- **Устройство:** любое, например `iPhone 13`.
- **Шаги:** открыть страницу (список «Подсказки» из трёх пунктов), `set_offline
  true`, подождать 5–6 секунд.
- **Симптом:** список подсказок пустеет; в `get_console` каждые ~3 с новая
  `Не удалось загрузить подсказки уровня 1`, в `get_network_errors` запросы
  `hints/1.json?t=…` с ошибкой сети; `get_state`: `hints.loaded = false`,
  `hints.count = 0`, `hints.error` заполнен.
- **Что должен написать QA:** при потере сети подсказки исчезают, ошибки
  повторяются и копятся; запрос каждый раз уходит заново (параметр `t`).
  В `fixed/` подсказки остаются, в консоли тихо.
- **Уровень:** MAJOR.

### 3. Быстрый свайп не срабатывает, медленный срабатывает

- **Устройство:** `iPhone 13`.
- **Шаги:** `swipe` по карточке справа налево на ~200 px за 120 мс →
  `get_state`: `level.index = 0`, `swipes = 0`. Тот же жест за 600 мс →
  `level.index = 1`, `swipes = 1`.
- **Что должен написать QA:** результат зависит от длительности жеста, а не от
  пройденного расстояния; приложить значения `get_state` после обоих свайпов.
  В `fixed/` оба жеста переключают уровень.
- **Уровень:** MAJOR.

### 4. Анимация «схлопывается» в части кадров

- **Устройство:** `iPhone 13`.
- **Шаги:** запустить смену уровня (медленный свайп из п. 3 либо любой, если
  жест сработал) и сразу снять `get_frames` 10 × 50 мс.
- **Симптом:** примерно в кадрах 3–6 карточка исчезает (`scale(0)`), потом
  появляется снова; на одиночном скриншоте после перехода всё в порядке.
- **Что должен написать QA:** в части кадров раскадровки карточка пропадает;
  перечислить номера кадров и время. В `fixed/` карточка плавно растёт.
- **Уровень:** MAJOR.

### 5. Кнопка «Старт» перекрыта плашкой cookie на узком экране

- **Устройство:** `set_device` ширина 320 px (мобильное, touch), высота 640 px.
- **Шаги:** открыть страницу, не закрывая плашку; `tap` по «Старт»;
  `get_screenshot`; `get_state`.
- **Симптом:** плашка (~132 px) закрывает кнопку, тап приходит в плашку;
  `started = false`. При ширине ≥ 360 px кнопка над плашкой и работает.
- **Что должен написать QA:** на 320 px «Старт» перекрыт плашкой cookie,
  тап не срабатывает; скриншот; сравнение с широким экраном. В `fixed/`
  кнопка поднята над плашкой, `started` становится `true`.
- **Уровень:** MAJOR.

## Критерий

- На `broken/` QA сам находит **≥ 4 из 5** с шагами воспроизведения и
  доказательствами (скриншот, значения `get_state`, строки консоли), вердикт
  `FAIL`.
- На `fixed/` — `PASS` **без ложных находок** уровня `BLOCKER`/`MAJOR`.
  `MINOR` допустимы, но разбираются (например, подсказки в `fixed/` при
  старте без сети показывают «Нет сети…»: это не баг).

Различия `broken/` и `fixed/` — только в местах багов: `diff -r broken fixed`.
